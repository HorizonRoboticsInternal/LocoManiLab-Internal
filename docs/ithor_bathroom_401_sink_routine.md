# 401 水池三阶段复合任务

任务：`IThorBathroomApproachSinkAndPutSpongeInSinkThenLiftSoapBottle`，仅支持 `scene-id 401`。

1. 走到水池碰撞几何 0.35 米内，连续保持 5 个控制步。
2. 把海绵放入水槽，与指定槽底碰撞体连续接触 1 秒。沿用海绵入槽原子任务的判定，不额外要求松手。
3. 肥皂瓶相对 reset 后初始高度抬高至少 0.10 米，抬升高度与海绵槽底接触同时连续保持 1 秒。第三阶段不要求抓握，不检查手部抓持信号。

必须按顺序执行。导航前已经放入的海绵需离开槽底后重新放入；提前举起的瓶子需降到抬升阈值以下再举起；仅中断海绵槽底接触不能使提前举瓶计入第三阶段。任一最终条件中断都会清零最终保持时间。普通 reset 和固定场景恢复使用的 `_reset_task_progress()` 均清空阶段进度。

新任务复用原子任务的固定海绵模型、缩放、槽底接触判定，以及原生肥皂瓶的高度读取。本任务单独设置 0.10 米抬升阈值；举瓶成功谓词在本复合任务内单独定义，不要求抓握，原子举瓶任务保持原判定。任务独立深拷贝 401 规格，独立设置导航出生点和瓶子池沿支撑区域，不继承公开原子环境。既有原子任务、复合任务、YAML 和场景资产不作行为修改。

瓶子使用与 401 原子举瓶任务相同的 `FloorPlan401:Soap_Bottle_1_10` 资产，在本组合任务的水池边竖直放置，四元数为 `[0.70710678, 0.70710678, 0.0, 0.0]`，使瓶子的局部 +Y 轴朝上。其模型、质量、碰撞与缩放保持原生配置。瓶子与海绵分放在靠近机器人一侧的两个池沿拐角，以避开外侧凸边：海绵放置中心 XY 为 `[-2.79, 1.28]`，瓶子为 `[-2.79, 1.82]`。瓶子的竖直姿态包围盒约为 `[0.099, 0.099, 0.182]` 米，静置 0.3 秒后中心约为 `[-2.789, 1.821, 1.116]` 米。水平包围盒包含泵头外廓，不能据此声称已验证实际抓持跨度。

```bash
  --scene-id 401 --onscreen
```
