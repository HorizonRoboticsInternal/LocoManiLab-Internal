# Holodeck 2209 闹钟复合任务

日期：2026-10-16。两个任务均仅支持 `scene_ids=[2209]`。

| 注册环境名 | 顺序 | 初始抽屉状态 |
|---|---|---|
| `HolodeckPlaceAlarmClockThenCloseDrawerThenPickBox` | 放入闹钟 → 关闭抽屉 → 拿起地面纸箱 | 100% 打开，与原子放入任务一致 |
| `HolodeckOpenDrawerThenPlaceAlarmClockThenApproachTrashCan` | 打开抽屉 → 放入闹钟 → 走到垃圾箱旁 | 30% 打开 |

闹钟、书桌、最上层抽屉、机器人站位和闹钟初始位姿直接继承 `HolodeckPlaceAlarmClockInDrawer` 当前工作区校准。闹钟保持原模型及 `CLOCK_SCALE=0.89`。复合任务配置由 loader 深拷贝读取，不修改原子任务的 spec。

各阶段连续保持 1 秒，按实际 `control_freq` 换算。放入阶段沿用原子任务的“接触指定抽屉底面”判定，并要求抽屉至少 80% 打开。关闭阶段要求同一抽屉不超过 20% 开度，闹钟仍接触底面；后续纸箱阶段要求上述状态继续成立。拿纸箱沿用原子任务的相对 reset 高度抬升超过 0.30 米判定，不增加抓握条件。导航复用 `HolodeckApproachTrashCan.success_distance`，计算机器人与指定垃圾箱碰撞几何的最短距离，要求不超过 0.35 米、阶段内水平移动至少 0.15 米，同时闹钟仍接触抽屉底面。

状态机只检查当前阶段。提前放入闹钟必须先移出再放入；进入关抽屉阶段时若已提前关闭，必须先恢复到至少 80% 开度再关闭；进入拿纸箱阶段时若已抬起，必须先放低再抬起；进入导航阶段时若已在垃圾箱旁，必须先离开目标范围再走近。

2209 原场景没有纸箱或垃圾箱。第一个任务只添加原子任务使用的 `Box_19`，保持 `BOX_SCALE=2.0` 和原子任务的直立方向，位置为 `[3.60, 5.24]`，在机器人身前、打开的目标抽屉下方的地面上。复用原子的 XML 构建和放置方法后，仅在新任务内按真实碰撞盒修正落地高度；原子方法的包围盒包含不可见调试区域，不能作为本任务的最终落地依据。第二个任务只在 `[5.50, 5.20]` 添加 117 的垃圾箱，位置靠近 `y≈6.0` 的墙面，复用已有复制方法和空心碰撞代理。共享场景 XML、原子任务实现和其他场景配置均未修改。

本次纸箱位置校准（2026-10-16）：纸箱中心在机器人前方约 0.704 米、横向偏移约 0.086 米；与打开的目标抽屉中心左右相差约 0.018 米，箱顶低于抽屉。定向复用第一个任务的 headless 初始化/稳定性检查，并核对实际几何位置、地面高度和其他 spec 不变。共执行两次 headless reset：首次附加诊断因箱底高于地面约 `5.6e-17` 米而未生成接触点，严格接触点断言失败；改为检查实际箱底高度后，最小用例复测通过。0.4 秒独立模拟中纸箱总位移约 `6.9e-6` 米，接触仅来自地面，机器人无出生碰撞。此次只修改该任务的纸箱位置配置及本文档，GUI/人工抓取仍未验证。

本次抽屉/垃圾桶校准（2026-10-16）：仅第二个任务的抽屉初始开度改为 30%（`qpos=0.0882`），垃圾桶从 `[5.50, 4.20]` 移至 `[5.50, 5.20]`，向 `y≈6.0` 的墙面移动 1 米。保留原场景家具，最终实测桶到墙最短碰撞距离约 0.505 米，到最近其他碰撞体约 0.204 米，机器人到桶初始碰撞距离约 1.990 米。任务成功说明及状态机测试的模拟初值同步为 30%，80% 打开门槛与后续阶段条件不变。几何诊断共做 3 次 headless reset：前两个更贴墙候选分别未满足预设墙距、与原家具相交，最终位置的单用例复测通过（`test_one_headless_reset_and_support_stability[HolodeckOpenDrawerThenPlaceAlarmClockThenApproachTrashCan]`，1 passed），同时覆盖机器人零碰撞、初始不成功、地面支撑和闹钟短时稳定性。完整 YAML 与本轮修改前快照比较，仅此任务的初始开度和垃圾桶位置改变；Python 语法编译及 `git diff --check` 通过。GUI、人工导航/全流程和数据采集未验证。
