# Bathroom 410 抽屉复合任务（2026-10-16）

两个新入口均仅支持 `scene_ids=[410]`；Bathroom 共 69 个任务（27 原子 / 42 复合），410 为 2 原子 / 2 复合。

| 环境名 | 按顺序完成的阶段 |
|---|---|
| `IThorBathroomOpenDrawerThenPutToiletPaperRollAndCloseDrawer` | 打开水池下方抽屉 → 放入纸卷 → 关上同一抽屉 |
| `IThorBathroomTakeSoapBottleFromDrawerThenStandOnSinkAndApproachToilet` | 从抽屉取出肥皂瓶 → 台面竖直摆放并释放 → 走到马桶旁 |

## 初始化与原子判定复用

实现位于 `tasks/composite/drawer_routines.py`，复用私有 `_BathroomDrawerTask` 初始化以及现有原子成功谓词，不继承公开原子环境。各自仅深拷贝 `FloorPlan410` 配置，原子规格、共享 YAML、资产和其他任务实现均未修改。

- 纸卷任务复用 `IThorBathroomToiletPaperRollIntoDrawer` 的机器人位姿 `xy=[-2.0, 2.57]`、yaw `-0.408238`、纸卷姿态/位置、抽屉实体与关节。仅此复合任务将抽屉初始开度设为 20%，仍需先打开至至少 80%。
- 肥皂瓶任务复用 `IThorBathroomTakeSoapBottleFromDrawer` 的机器人位姿、打开的抽屉与瓶子在抽屉中的初始配置。取出阶段直接复用瓶子根节点相对初始高度抬升至少 `0.30 m` 的原子判定，不另外增加抓持要求。
- 使用同一抽屉 `FloorPlan410:Drawer_c81edb51_0`，关节 `drawer_3593bc74e14afaf576668610fec0f56f_1_1_0_joint_0`。支撑区域和 `-0.012 m` 抽屉底面校准沿用原子任务。
- 马桶目标精确绑定 `FloorPlan410:Toilet_1_4`，沿用 `ExactSceneNavigation` 的碰撞几何最短距离 `≤0.35 m` 判定；记录初始距离。没有自动移动机器人或固定底盘。

肥皂瓶放置在原配置指定的 `FloorPlan410:CounterTopMesh_fb983d72_22`。合法位置为同一台面的 `receptacle:0/1/2/3` 四个区域的并集，包括抽屉外宽约 12.8 cm 的细长条台面。该窄边小于直立瓶子的语义包围盒宽度，因此本任务检查瓶子语义中心的 XY 落在其中一个区域，允许包围盒略微伸出台面；仍要求真实台面支撑接触、底部高度正确、竖直、无非法穿透和双手释放。不会把四个区域合并成一个大矩形，水池空隙仍非法。实际向上的台面接触位于 `z≈0.806 m`，比导出支撑平面 `0.818 m` 低 12 mm；在此任务的各区域副本上施加 `-0.012 m` 高度偏移，保留区域 0 为主引用，并在 metadata 的 `placement_regions` 列出全部区域，不改语义注册表或原子配置。

## 成功与顺序

每个中间阶段必须连续满足 5 个控制步；最终阶段按实际 `control_freq` 连续保持 1 秒。下一阶段若在进入时已经完成，必须先恢复非成功状态再完成。正常 reset 与固定采集恢复物理状态后的 `_reset_task_progress()` 都清空阶段、计时和消息状态。

- 纸卷：抽屉开度 `≥80%`；在仍打开的状态下满足原子底面接触；最后同一抽屉开度 `≤20%` 且纸卷继续接触底面。保留原子任务允许任意纸卷朝向、部分伸出、仍抓持的语义，不额外要求完整包围盒包含或释放。单独把纸卷放到关闭抽屉中不能跳过顺序。
- 肥皂瓶：先抬升 `≥0.30 m`；再复用原子的竖直、支撑高度、接触、穿透和释放辅助判定，要求本地 +Y 轴与世界竖直夹角不超过 20°、瓶子中心 XY 位于任一合法台面区域内、底部与支撑平面偏差不超过 3 cm、真实支撑接触、无非法穿透、双手释放；最后机器人到达指定马桶，同时瓶子继续满足以上摆放条件。
- 最终条件中断立即清零；即使上一控制步已经成功，当前物理条件不满足也返回失败。进度与最终成功分别判断，不会单靠中间阶段累计时间成功。
