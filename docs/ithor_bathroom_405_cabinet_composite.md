# 405 柜内取肥皂瓶并放台面复合任务

新增任务：`IThorBathroomOpenCabinetThenPlaceSoapBottleOnCounterAndCloseCabinet`，仅支持 Scene 405。

任务按以下顺序执行，开门和抬升阶段各连续保持 5 个控制步，放置和最终关门阶段各保持 1 秒：

1. 柜门初始打开 20%，打开同一柜门到至少 80%；肥皂瓶仍须接触柜内低支撑面，不能先取瓶再开门。
2. 弯腰取柜内瓶子：原生肥皂瓶相对 reset 初始高度抬高至少 0.30 米；本阶段不检查抓握状态、手部状态或抓握历史；柜门保持至少 80%，瓶子不得穿透柜体。低位布局要求下探取物，但不额外设置腰部关节角度门槛。
3. 将瓶子放到水池台面并松手，连续保持 1 秒，按实际控制频率换算步数。仅要求瓶子接触台面碰撞体顶面且左右手均不接触瓶子；包括水池旁细长条台面，排除水池开口和盆内。无需瓶身完整落入原矩形区域，不检查瓶底高度、穿透深度、直立姿态或柜门开度。
4. 关闭同一柜门到不超过 10%；瓶子继续接触台面且双手释放，与关门状态一起连续保持 1 秒，按实际控制频率换算步数；中断立即清零。

放置阶段进入时若已经接触台面并松手，直接开始累计 1 秒，无需拿起重放；其他阶段仍保留提前完成须恢复后重做的顺序门槛。普通 reset 和固定场景采集的 `_reset_task_progress()` 均重置高度基准、阶段及保持计数。

## 实体与隔离

- 门关节：`cabinet_4d8401876c23e5ef4325895368767cfe_1_1_0_joint_0`。

- 放置目标：`FloorPlan405:CabinetBodyMesh_45407f37_25` 的可见台面顶面，包含水池旁细长条，排除水池开口和盆内。本任务加载时将横跨水池的原 `collision_8` 与 `collision_11` 替换为任务专用 XML 中的 40 个凸三棱柱，其水平形状来自原可见台面网格的顶面三角形，保留水池孔洞；上下高度沿用原碰撞体范围。原 `receptacle:7` 仅提供约 0.994 米的支撑高度参考；接触点距该平面不超过 3 厘米，用于区分台面接触与柜体低处接触，不限制瓶底或瓶身范围。

## 水池隐形支撑修复与检查结论（2026-10-19）

- 原因：原 `collision_11` 是覆盖完整台面外接矩形的盒体，横跨水池开口；其下方 `collision_8` 同样覆盖盆体空间。上一版接受整个台面盒体的接触，导致开口上方的隐形支撑被误判为有效放置。
- 改动：仅在本复合任务内替换这两个碰撞体，加载 `objects/manual/bathroom_405_countertop_collision.xml` 的台面三角棱柱，保留可见孔洞及细长条。成功判定仅接受替换后的台面接触，仍要求双手松开连续 1 秒；水池本身的碰撞不计为台面接触。元数据用 `placement_contact_geoms` 记录有效碰撞体列表。
- 隔离：共享场景 XML、原子任务、其他任务和其他场景不变；任务专用 XML 仅由本复合任务引用。静态测试确认替换前的场景副本保持不变，除两块盒体外的原柜体元素保留，原子类不继承替换逻辑。
